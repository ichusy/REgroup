# REgroup

**👉 Ouvrir le site : https://ichusy.github.io/REgroup/**

Tous mes jeux quotidiens regroupés dans un système solaire : chaque jeu est une planète, un clic ouvre le jeu, et les planètes s'allument au fil de la journée.

Le bouton **Liste** affiche les jeux en blocs. Depuis la liste, **Modifier** permet d'ajouter, de supprimer et de réordonner les sites, et de choisir un logo. Les changements et la progression du jour sont gardés dans le navigateur.

Pour ajouter un site à la liste de base, ajoute une ligne dans `DEFAULT_SITES` dans `index.html`.
