# REgroup

Tous mes jeux quotidiens regroupés sur une seule page, accessibles en un clic.

Ouvre `index.html` dans un navigateur. Le bouton **Modifier** permet d'ajouter, de supprimer et de réordonner les sites, et de choisir un logo. Les changements sont gardés dans le navigateur.

Pour ajouter un site à la liste de base, ajoute une ligne dans `DEFAULT_SITES` dans `index.html`.
